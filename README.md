# 🌌 Bodhipanya Quantum Dharma: The Engineering Journal

**"วารสารธรรมะวิศวกรรม: ถอดรหัสระบบจิตผ่านเลนส์ควอนตัมฟิสิกส์"**

โปรเจกต์นี้คือการพลิกโฉมการนำเสนอสัจธรรมทางพุทธศาสนา โดยน้อมนำแก่นคำสอนของ **พระราชพรหมยาน (หลวงพ่อฤาษีลิงดำ)** มาบูรณาการเข้ากับ **"ระบบคิดเชิงวิศวกรรม" (Engineering Thinking)** และ **"ควอนตัมฟิสิกส์" (Quantum Physics)** เพื่อสร้างสรรค์คลังธรรมะที่อธิบายกลไกของจิตใจได้อย่างเป็นรูปธรรม ไร้ความงมงาย และสัมผัสได้จริงผ่านสถาปัตยกรรมซอฟต์แวร์

## 📜 The "Scrollytelling" Experience (ประสบการณ์การอ่านแบบอินเทอร์แอกทีฟ)
แอปพลิเคชันนี้ถูกออกแบบในรูปแบบ **วารสารโปร่งแสง (100% Transparent UI)** ผสมผสานเทคนิค *Scrollytelling* 
เมื่อผู้อ่านเลื่อนหน้าจอ (Scroll) เพื่ออ่านบทวิเคราะห์ระบบจิตในแต่ละโมดูล **"เครื่องยนต์ฟิสิกส์ควอนตัม" (Quantum Physics Engine)** ที่อยู่เบื้องหลังจะทำการเปลี่ยนสภาวะ (State) ของ "ก้อนจิต 3,000 โหนด" ให้สอดคล้องกับเนื้อหาที่กำลังอ่านโดยอัตโนมัติ

## ⚙️ The 5 Engineering Modules (๕ โมดูลถอดรหัสจิต)

เราวิเคราะห์ความทุกข์ การเวียนว่ายตายเกิด และการหลุดพ้น ประดุจการทำ **System Analysis** และ **Debugging** ระบบ:

*   **Module 01: System Overload (อุปาทานขันธ์ ๕)**
    *   *Physics:* Hooke's Law (F = -kx)
    *   *State:* จำลองสภาวะที่จิต (วิญญาณ) ยึดติดกับฮาร์ดแวร์ (ร่างกาย) ด้วยค่าความตึงเครียดสูง จนระบบเกิดความปั่นป่วน
*   **Module 02: Thermodynamic Equilibrium (อารมณ์พระนิพพาน)**
    *   *Physics:* Zero Entropy (สภาวะเอนโทรปีเป็นศูนย์)
    *   *State:* เมื่อตัดกิเลส ระบบจะเข้าสู่ Ground State หรือสภาวะพื้นฐานที่เสถียรที่สุด การไหลเวียนของอนุภาคราบเรียบ ไร้การเสียดทาน
*   **Module 03: Causality Network (กฎแห่งกรรม)**
    *   *Physics:* Wave Propagation & Butterfly Effect
    *   *State:* จำลองโครงข่ายใยแมงมุมควอนตัม ทุกเจตนาคือการสร้างคลื่น (Ripple) ที่จะแผ่ขยายและสะท้อนกลับมาสู่จุดกำเนิดเสมอ
*   **Module 04: Subsystem Isolation (ตัดขันธ์ ๕ ยามป่วย)**
    *   *Physics:* Wave-Particle Dissociation
    *   *State:* เมื่อฮาร์ดแวร์ (กาย) แจ้งเตือนข้อผิดพลาด (ป่วย/เจ็บปวด) ระบบผู้สังเกตการณ์ (จิต) จะทำการปลดล็อกตัวเอง ลอยตัวอยู่เหนือความผันผวนอย่างสงบ
*   **Module 05: Entangled Field (พรหมวิหาร ๔)**
    *   *Physics:* Quantum Entanglement & Harmonic Resonance
    *   *State:* รันโปรโตคอลแห่งความเมตตา สร้างสายใยพลังงานเชื่อมโยงทุกโหนดเข้าด้วยกัน เพื่อรักษาสมดุลของระบบนิเวศจักรวาล

## 🛠️ Tech Stack & Architecture
- **Core Engine:** HTML5 Canvas, Vanilla JavaScript (Custom Physics Engine)
- **Styling:** Tailwind CSS (กำหนดค่าสีล้ำสมัย: Gold, Cyan, Alert Red, Terminal Green)
- **UI Mechanism:** `Intersection Observer API` สำหรับตรวจจับการเลื่อนหน้าจอเพื่อทริกเกอร์ Physics Engine
- **Aesthetics:** Heavy Text-Shadow & Glowing Effects เพื่อให้ตัวอักษรลอยเด่นชัดเจนบนฉากหลังที่เต็มไปด้วยอนุภาคที่กำลังเคลื่อนไหว
- **Deployment:** Single-file Web Application (No Build Tool Required)

## 🚀 Installation (วิธีรันโปรเจกต์)
นี่คืองานวิศวกรรมที่เรียบง่ายแต่ทรงพลัง ไม่ต้องพึ่งพาเซิร์ฟเวอร์หรือไลบรารีภายนอกให้ซับซ้อน:
1. Clone repository นี้ หรือดาวน์โหลดไฟล์ `index.html`
2. ดับเบิลคลิกเพื่อเปิดบน Web Browser (แนะนำ Chrome หรือ Safari รุ่นล่าสุด)
3. เลื่อนเมาส์ลงมา (Scroll down) และปล่อยให้สัจธรรมทำงาน
