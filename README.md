# 🌌 Bodhipanya Quantum Dharma (คลังธรรมะควอนตัม)

**"ยานพาหนะแห่งธรรมะในยุคดิจิทัล และ เครื่องเจริญสติแบบอินเทอร์แอกทีฟ"**

โปรเจกต์นี้ถือกำเนิดขึ้นจากเจตนารมณ์ที่จะน้อมถวายบูชาพระคุณและสืบสานคำสอนของ **"หลวงพ่อฤาษีลิงดำ (พระราชพรหมยาน)"** โดยการบูรณาการสัจธรรมทางพุทธศาสนาเข้ากับภาษาของวิทยาศาสตร์ยุคใหม่ (Quantum Physics) เพื่อเปลี่ยนนามธรรมทางจิตที่เข้าใจยาก ให้กลายเป็นภาพเคลื่อนไหวเชิงปฏิสัมพันธ์ที่ผู้คนสามารถเข้าถึงและตื่นรู้ได้ด้วยปลายนิ้ว

## 🔬 Core Concept: ทฤษฎีและสถาปัตยกรรม
โปรเจกต์นี้จำลองสภาวะจิตใจเป็น **"ก้อนจิต 3,000 โหนด"** (Quantum Nodes) ที่เคลื่อนไหวอยู่บนโครงข่ายจักรวาล โดยใช้หลักการทางฟิสิกส์และคณิตศาสตร์มาเป็นเครื่องมือ (Metaphor) ในการอธิบายธรรมะ:
- **Hooke's Law (แรงตึงผิว):** อธิบายความยึดมั่นถือมั่น (อุปาทาน)
- **Entropy (ความไร้ระเบียบ):** อธิบายความวุ่นวายของกิเลสและกฎอนิจจัง
- **Ground State (สภาวะพื้นฐานที่เสถียรที่สุด):** อธิบายความสงบแห่งอารมณ์พระนิพพาน
- **Quantum Entanglement (การพัวพันเชิงควอนตัม):** อธิบายการแผ่กระแสกรรมและพรหมวิหาร 4

## 🗂️ The 5 Master Modules (โมดูลการทำงานหลัก)

แอปพลิเคชันนี้รวบรวมระบบจำลองฟิสิกส์ทางจิตไว้ในหน้าเดียว (Single Page Application) แบ่งเป็น 5 โมดูล ดังนี้:

### 1. โมดูล 01: อุปาทานในขันธ์ 5 (The Illusion of Form & Mind)
- **Physics Engine:** Hooke's Law 
- **Interactive:** เลื่อนปรับแถบ "อุปาทาน" (ความยึดติด) หากยึดมากโหนดจิตจะรวมตัวกันแน่นจนเกิดความเครียด (Stress) หากปล่อยวาง (แผ่สติ) โหนดจะคลายตัวเป็นอิสระ

### 2. โมดูล 02: อารมณ์พระนิพพาน (The Quantum Ground State)
- **Physics Engine:** Entropy Reduction
- **Interactive:** ควบคุมความผันผวนของระบบ (Thermal Turbulence) สังเกตอนุภาคที่วิ่งวุ่นวายกลับคืนสู่วงโคจรที่สงบและเสถียรที่สุด (Zero Entropy)

### 3. โมดูล 03: กฎแห่งกรรม (The Quantum Causality & Karma Engine)
- **Physics Engine:** Causality Ripples / Butterfly Effect
- **Interactive:** สร้าง "เจตนา" (กุศล/อกุศล) และดูคลื่นการสั่นพ้องที่แผ่ขยายไปกระทบโหนดอื่นๆ ในระบบ เพื่อทำความเข้าใจกฎแห่งเหตุและผล

### 4. โมดูล 04: ตัดขันธ์ 5 ยามป่วย (Quantum Pain Transmutation)
- **Physics Engine:** Wave-Particle Dissociation
- **Interactive:** ปรับระดับความเจ็บปวดทางกาย (อนุภาคสีแดง) และกดปุ่ม "วางจิต" เพื่อแยกผู้สังเกต (Observer) ออกจากคลื่นความเจ็บปวด (กายป่วย แต่ใจไม่ป่วย)

### 5. โมดูล 05: พรหมวิหาร 4 (The Quantum Compassion & Entangled Field)
- **Physics Engine:** Quantum Entanglement & Harmonic Resonance
- **Interactive:** ควบคุม 4 เสาหลัก (เมตตา กรุณา มุทิตา อุเบกขา) เพื่อแผ่ขยายความสว่างไสว สร้างเส้นใยเชื่อมโยง และเยียวยาโหนดที่มีความทุกข์ให้เข้าสู่สมดุล

## 💻 Tech Stack & UI Design
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ทำงานผ่าน Canvas API)
- **Architecture:** Single-file Web Application (ไม่มี External Libraries เพื่อความรวดเร็วและคงทน)
- **UI Design (100% Transparent):** หน้าต่าง UI ใสปิ๊งไร้พื้นหลัง (100% Transparent) เพื่อให้เห็นสภาวะธรรมด้านหลังแบบไร้ขอบเขต ใช้เทคนิค Heavy Text-Shadow (สีดำเข้ม) เพื่อให้ตัวหนังสืออ่านง่ายและลอยเด่นขึ้นมาจากคลื่นควอนตัม
- **Audio:** Web Audio API สร้างคลื่นเสียงสมาธิบำบัด (Solfeggio Frequencies 432 Hz และ 528 Hz)

## 🚀 Installation & Usage (การใช้งาน)
โปรเจกต์นี้ถูกออกแบบมาให้เรียบง่ายและทำงานได้ด้วยตัวเอง (Self-contained)
1. ดาวน์โหลดไฟล์ `index.html` หรือ Clone Repository นี้
2. ดับเบิลคลิกเปิดไฟล์ `index.html` บน Web Browser ใดก็ได้ (Chrome, Safari, Edge)
3. ใช้งานระบบ Interactive ได้ทันที โดยไม่ต้องติดตั้งเซิร์ฟเวอร์หรือไลบรารีเพิ่มเติม
